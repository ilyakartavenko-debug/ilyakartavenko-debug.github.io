# Портфолио — как выложить и что поменять

## Шаг 1. Поменять контакты (2 минуты)

Открой `index.html`, найди комментарий `КОНТАКТЫ` (одно место в файле, ближе к концу)
и замени три значения:

| Заглушка | На что менять |
|---|---|
| `https://t.me/ЗАМЕНИ_НИК` | свой ник в Telegram |
| `tel:+7ЗАМЕНИТЕЛЕФОН` | телефон в формате `tel:+79001234567` |
| `mailto:ЗАМЕНИ@ПОЧТУ.ru` | рабочая почта |

Больше нигде в файле контактов нет — правится только здесь.

## Шаг 2. Выложить на GitHub Pages (20 минут, бесплатно, https сразу)

Делается один раз, дальше обновление — в одну команду.

1. Зарегистрируйся на github.com, если аккаунта ещё нет.
2. Создай **публичный** репозиторий с именем `<твой-логин>.github.io`
   — например `ilyakartavenko.github.io`. Имя должно совпадать с логином, иначе
   сайт откроется по адресу с подпапкой.
3. В этой папке выполни:

```bash
git init && git add . && git commit -m "portfolio" && git branch -M main && git remote add origin https://github.com/ТВОЙ-ЛОГИН/ТВОЙ-ЛОГИН.github.io.git && git push -u origin main
```

4. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save.**
5. Через 1–2 минуты сайт откроется по адресу `https://твой-логин.github.io`

Обновление после правок:

```bash
git add . && git commit -m "update" && git push
```

## Шаг 3. Домен (позже, но лучше сразу)

Свой домен вида `имя-фамилия.ru` стоит 200–400 ₽/год и заметно поднимает доверие
в письмах агентствам — с адреса на github.io пишет студент, с собственного домена
пишет подрядчик.

Как подключить: в настройках домена у регистратора создать записи

```
A     @     185.199.108.153
A     @     185.199.109.153
A     @     185.199.110.153
A     @     185.199.111.153
CNAME www   твой-логин.github.io
```

затем в **Settings → Pages → Custom domain** вписать домен и включить
**Enforce HTTPS**. Сертификат GitHub выпустит сам.

## Что внутри

Две страницы, обе без внешних зависимостей: ни шрифтов с CDN, ни скриптов,
ни аналитики. Открываются мгновенно, тёмная и светлая темы переключаются
по системной настройке.

**`index.html`** — портфолио исполнителя. Для писем агентствам и заказчикам
проектов. Разделы: услуги с ценами · 4 кейса · блок для агентств (субподряд,
белый лейбл) · стек · тарифы · процесс · контакты.

**`studii.html`** — лендинг продукта для студий. Совсем другая аудитория:
владелица студии, не технарь, скептична к нейросетям. Поэтому там нет слова
«стек», зато есть сравнение «как обычно / с системой», раздел «почему это
не нейросеть пишет ерунду», три тарифа и пять частых вопросов.

**Ссылку на `studii.html` вставляй в письма студиям, на `index.html` —
в письма агентствам.** Это разные продажи: студии покупают подписку,
агентства — руки.

После публикации адреса будут:
`https://твой-логин.github.io/` и `https://твой-логин.github.io/studii.html`

## Что добавить, когда появятся

- **Скриншоты.** Сейчас кейсы текстовые. Дашборд TenderBot и панель студий
  в виде картинок поднимут доверие сильнее любого текста. Замажь клиентские
  данные и вставь 3–4 изображения.
- **Отзывы.** Как только будут первые — отдельным блоком после кейсов,
  с именем и компанией. Без имени отзыв не работает.
